# أساسيات الهندسة الصناعية

كتاب جامعي عربي مفتوح في أساسيات الهندسة الصناعية، تأليف **د. رامز عساف** (2026).

- **الموقع:** https://ramizassaf.github.io/industrial-engineering-basics/
- **تحميل PDF:** [Industrial_Engineering_Basics_Ramiz_Assaf.pdf](Industrial_Engineering_Basics_Ramiz_Assaf.pdf)
- **القراءة على الويب:** [book.html](book.html)

## المحتويات

1. مدخل إلى الهندسة الصناعية وفهم النظم
2. العوامل البشرية والسلامة المهنية
3. القياس والبيانات
4. العمليات والإنتاجية
5. الجودة وضبط العمليات
6. المخزون وسلاسل التوريد
7. بحوث العمليات واتخاذ القرار
8. التحليل الاقتصادي الهندسي
9. التحسين والاستدامة واستمرارية العمل

إضافة إلى مشروع تطبيقي ختامي، وملحق لحلول المسائل الحسابية الاثنتين والثلاثين، وملحق للمعادلات والرموز، ومسرد عربي إنجليزي.
